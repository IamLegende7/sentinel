Adding new tiles:

    - add "namespace:id": "/path/to/texture.png" to resources/textures/defaults/texture_tile_defaults.json
    WATCH OUT:
        - use $resources$ for    RESOURCE_DIR
        - use $textures$ for     TEXTURE_DIR
        - use $texturepacks$ for TEXTUREPACK_DIR

    HOW TO HITBOXES:
        Moveboxes:
            --> ...are hitboxes, that collide with other moveboxes. they are for walls and such
            - type = 1
            - put "moveboxes": [[type (1 for moveboxes), 0, 0, x_offset, y_offset, width, height], <more moveboxes if you want>]
            - x,y,x_offset,y_offset,width,height are in percent!
                --> calculate using (pixels / full size of texture (aka 16 for a 16x16 texture)) * 100
