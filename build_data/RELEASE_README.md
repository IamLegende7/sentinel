# Sentinel

This is the compiled version of my game "Sentinel".
To run the game execute ```run.sh``` (or ```run.bat``` if you are on Windows).

All files needed for execution are included in this folder, so feel free to delete the other files, if you don't want some random source code hanging around on your PC.
Also: all files use relative paths; you can move this folder anywere you like, as long as you **don't change it's internal structure**.

Please report all bugs and issues you find at [the projects github](https://github.com/IamLegende7/sentinel/issues).
I will do my best to fix every bug found.

Thank you for trying my game <3
